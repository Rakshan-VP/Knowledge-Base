> This note covers the **fundamental Part Design tools and features in FreeCAD** used to create and modify parametric 3D solid models. It focuses on the basic workflow of creating sketches, generating features, and building stable bodies using additive and subtractive operations.

## Overview 

**Part Design** is FreeCAD's workbench for creating **parametric 3D solids** by combining sketches with feature-based operations. This note covers the essential Part Design tools and workflow required to build, modify, and manage solid bodies effectively.
