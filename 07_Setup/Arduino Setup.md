## Overview

This note documents the installation and configuration of **Arduino IDE**, including the initial setup, required preferences, board packages, libraries, and other configuration needed for Arduino development.

- **OS:** Linux
- **Distribution:** Fedora 44
- **Desktop Environment:** KDE Plasma
- **Package:** AppImage

## Installation

- Download the Linux AppImage for Arduino IDE from the official Arduino website.
- Make the AppImage executable 

	```bash
	chmod +x arduino-ide_*.AppImage
	```

- Run Arduino IDE
    
	```bash
	./arduino-ide_*.AppImage
	```
